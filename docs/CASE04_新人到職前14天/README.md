| 順序 | 場合 | 用哪一份 |

| 1 | 業務自己先讀 | `CASE04_案例母稿.md` |

## 檔案

### 核心文件
- `CASE04_案例母稿.md` — 完整案例：產業背景、三輪提問設計、Day 3／7／14 產出摘要、判斷收斂、對外主張邊界、四處編輯校訂、DEMO 腳本、製作者備註
- `CASE04_主管提問指引與可複製指令.md` — **給客戶的操作教學**：固定開頭、三件事、三種現成模板、紀錄口徑與分母規則、五個常見錯誤
- `CASE04_案例文件.html` — 案例文件網頁版（可分享，含指令一鍵複製）

### 對外素材（`assets/`）
- `CASE04_客戶DEMO簡報.pptx` — 14 頁可編輯簡報
- `CASE04_客戶DEMO簡報.pdf` — 同上，PDF 版
- `CASE04_社群貼文海報_4x5.png` — 1080×1350，LinkedIn／粉專貼文配圖
- `CASE04_電子報完整海報.png` — 1120×1584，電子報／海報演示

### 文案
- `CASE04_LinkedIn粉專與電子報文案.md` — LinkedIn 長短版、7 頁輪播、粉專版、電子報長短版、業務私訊、發布前檢查表

### 可再編輯原始檔（`source/`）
- `海報原始檔_社群4x5.html`、`海報原始檔_電子報完整版.html` — 改文字後用無頭瀏覽器重新截圖即可
- `簡報產生器_pptxgenjs.js` — 重新產生簡報用
