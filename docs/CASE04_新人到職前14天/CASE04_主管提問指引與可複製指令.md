# 主管提問指引｜Traitty AI 怎麼問，才問得出可用的答案

> 適用對象：門市／現場／第一線責任主管。不需要會寫 Prompt，不需要懂測驗。
> 使用時機：新人到職期、帶教期、日常管理事件。

---

## 一、只要記住三件事

```
① 貼上固定開頭  →  ② 說出實際情況  →  ③ 問下一步怎麼做
```

**不需要**自己描述「這個人的特質是什麼」——那是 Traitty AI 已經有的資料。您只要說**您看到什麼**。

---

## 二、固定開頭：「事實—特質—驗證模式」

每次提問前，先貼上這一段：

```text
請把我提供的現場事實、系統中的 Traitty 特質線索與你的推論分開，判斷特質和現場反應是否有相符或可能關聯，也列出其他可能原因；再提出需要驗證的行為假設、我下一步可以直接問或做的事情，以及可觀察的工作指標。資料不足請明確說明，不要把推論當成事實。
```

**這一句幫您要到六件事**：分開事實與推論／判斷是否有關／列出其他原因／預測可觀察行為／給您可直接做的事／告訴您要記錄什麼。

---

## 三、接著寫您的三件事

```text
我的情境：
我是＿＿＿＿，目前正在＿＿＿＿。

我觀察到：
＿＿＿＿（他說了什麼、做了什麼、發生幾次、結果如何）

我想知道：
這可能和他的哪些特質有關？我現在應該怎麼問、怎麼做，接下來要觀察什麼？
```

### 寫「我觀察到」的三個要訣

| 要訣 | ❌ 這樣寫 | ✅ 改成這樣 |
|---|---|---|
| 寫行為，不寫評價 | 「他態度不積極」 | 「被問到學習狀況，他三次都回答『都還好』」 |
| 帶次數與情境 | 「常常出錯」 | 「這班操作 22 筆，其中 2 筆需要資深同仁更正，都發生在數量與用餐方式欄位」 |
| 分開「他自己發現」與「別人指出」 | 「錯了 3 次」 | 「外部更正 1 筆、他送出前自行修正 2 筆」 |

---

## 四、Traitty AI 會回您五層

> 觀察事實 → 特質線索 → 關聯判斷 → 行為假設 → 驗證與行動

**關聯判斷只會用這四種說法**，不會給您非黑即白的結論：

`有相符線索` ／ `部分相符` ／ `目前無法判斷` ／ `現有觀察暫不支持`

這是在回答「**是否可能有關**」，不是說「特質造成了這件事」。

---

## 五、四條一定要寫進去的邊界

在指令最後加上這幾句，答案才不會失控：

```text
請不要預測誰會離職，也不要判斷誰適不適任。
不要自行設定公司制度、合格門檻或工作標準。
不需要判斷公司權責、HR 權限、薪資、排班或升遷制度。
資料不足請明確說明，不要把推論當成事實。
```

> 這些屬於公司權責，應依貴公司職務權限、排班制度、人事規章及法令辦理。

## 六、三種現成模板

### 模板 A｜即時情境（當班或下一班前）

當某位成員突然出現新狀況時使用，不必重新輸入整批資料。

```text
請把我提供的現場事實、系統中的 Traitty 特質線索與你的推論分開，判斷特質和現場反應是否有相符或可能關聯，也列出其他可能原因；再提出需要驗證的行為假設、我下一步可以直接問或做的事情，以及可觀察的工作指標。資料不足請明確說明，不要把推論當成事實。

今天出現一個新狀況：

對象：
發生時間與工作情境：
我實際看到或聽到的事：
我當下怎麼回應：
目前造成的工作影響：

請告訴我：
1. 我現在最需要先確認什麼？
2. 我可以怎麼自然地問？
3. 今天或下一班可以做哪一個小幅度調整？
4. 接下來要觀察哪兩個具體反應？

請不要預測他是否會離職，也不要把單一行為直接解讀為態度、能力或適任性問題。只處理互動、帶教與工作觀察，不判斷公司制度或權責。
```

### 模板 B｜每週更新（第 7、14、21 天重複使用）

**每次只規劃下一週，不要一次預設整個月。**

```text
請把我提供的現場事實、系統中的特質線索與待驗證推論分開，重新檢查我們上次的判斷。

請說明原本的假設是「初步獲得支持／部分獲得支持／目前未獲支持／資料仍不足」，並列出支持的現場證據、與假設不一致的現象，以及其他可能原因。這幾天的變化不一定都是我的調整造成的，請不要因為時間上先後發生，就直接認定有因果關係。

對象：
上次的假設：
我採取的做法：
這一週的現場紀錄：
新人／成員自己怎麼說：
哪些改善了：
哪些沒有改變：
本週新出現的情況：

請告訴我：
1. 原本哪些推測得到實際資訊支持？
2. 哪些可能是我過度解讀？
3. 哪些仍然無法判斷？
4. 上週做法中，哪些應該保留、停止或微調？
5. 下一週最重要的一個帶教／管理目標是什麼？
6. 下一週可直接執行的簡單行動，以及週末需要確認的工作事實。

請不要把一週內的變化直接寫成長期成效或因果關係，也不要預測是否會離職。
```

### 模板 C｜階段回顧（第 14 或 30 天）

```text
請把我提供的現場事實、系統中的特質線索與待驗證推論分開，做一次階段回顧。

- 支持度只使用「初步支持／部分支持／目前不支持／資料不足」。
- 每項判斷都要列出支持證據、反例、其他可能原因及缺少的資料。
- 如果一個假設包含兩個原因，請拆開判斷，不要合併成單一結論。
- 不要用時間先後證明我的調整造成行為改變。
- 不要把零錯誤、零提問或時間縮短，單獨解讀為已熟練或適應改善。
- 不要自行設定公司標準、晉級資格、合理工時、求助規則或主管權限。
- 不要判斷誰可以獨立作業，也不要推估離職意圖、離職風險或留任機率。

【紀錄口徑】
【前期對照摘要】
【本期逐日紀錄】
【我另外問到的回饋】

請依以下架構回答：
一、最終假設檢核（原始假設／支持度／支持證據／反例／其他原因／已變清楚的一項／仍無法判斷的一項）
二、帶教方式如何調整（保留、減少或更換哪一項＋理由／一句我可以直接問的話／下一階段可先採取的一個動作／兩項最少要追蹤的工作指標）
三、整體判斷（我的哪些原始印象被修正／出現哪些有利的管理條件／哪些不能確認因果／目前仍不能得出哪些結論／我最需要注意哪一項判斷偏誤）

請用精簡表格呈現，不要重新做完整性格分析。
```

## 七、中間這幾天，主管要記什麼

**每人每天不超過 1 分鐘。先把用語定義好，AI 才不會誤讀。**

| 用語 | 定義 |
|---|---|
| **外部更正** | 對方尚未發現，由他人指出後才更正 |
| **自行修正** | 對方先發現，並在他人指出前修正 |
| **主動提問／求助** | 未經詢問，由對方主動提出 |
| **被問後回答** | 您用具體問句後對方才說出的內容，**不算主動** |
| **未排班／未參與** | 沒有觀察機會，**不能記成 0 次錯誤或 0 次提問** |

**每人每天只記三格：**

```
① 兩項工作指標（要有分母：做了幾筆 / 其中幾筆需更正；遇到幾次例外 / 其中幾次主動問）
② 一項具體的進步或做對的事
③ 有沒有新的例外情境
```

> **為什麼一定要有分母？**
> 「今天 0 次提問」可能代表他今天根本沒遇到新狀況，不代表退步。
> 「今天 0 筆錯誤」可能代表今天訂單單純，不代表已經熟練。

## 八、五個常見錯誤

| # | 錯誤做法 | 為什麼有問題 | 改成 |
|---|---|---|---|
| 1 | 自己先寫出對方的特質再請 AI 分析 | 變成 AI 重述您的分析，失去產品價值 | 只寫觀察，讓 AI 去對應特質資料 |
| 2 | 一次要求規劃 30／60／90 天 | 新人變化很快，計畫兩天就過期 | 每次只決定「現在」與「下一週」 |
| 3 | 問「他是不是想離職」 | 特質資料無法支持離職預測 | 問「我下一班該觀察什麼、怎麼問」 |
| 4 | 把 AI 的建議當成公司規定執行 | AI 不知道貴公司的權限與制度 | 先與門市既有流程核對，再執行 |
| 5 | 只記「錯了幾次」 | 沒有分母，下一輪無法判斷 | 記「做了幾筆／其中幾筆需更正」 |

## 九、一頁速查

```
┌─────────────────────────────────────────┐
│ 1. 貼上固定開頭（事實—特質—驗證模式）        │
│ 2. 寫三件事：我的情境 / 我觀察到 / 我想知道   │
│ 3. 加上四條邊界（不預測離職、不判適任、        │
│    不設公司標準、不答權責）                   │
│ 4. 拿到五層答案，挑「一句話」跟「一個動作」執行 │
│ 5. 每天記 1 分鐘（要有分母）                  │
│ 6. 第 7 天用模板 B 回來更新                   │
└─────────────────────────────────────────┘
```

**Traitty AI 提供的是決策輔助，不是決策本身。** 最終安排仍應依貴公司職務權限、排班制度、人事規章與法令執行。
